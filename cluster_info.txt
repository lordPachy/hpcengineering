The login requires VPN access, which in turn requires 2FA (two‑factor authentication). Windows and macOS users can refer to the official PoliMi documentation (https://www.ict.polimi.it/network/vpn/) and connect to the Mathematics Department portal. For GNU/Linux users, until official PoliMi support is available, it is recommended to use the CLI FOSS at https://github.com/yuezk/GlobalProtect-openconnect and follow the README there for installation; to connect, the minimum command is: 
`sudo gpclient connect gp-dmat-saml.vpn.polimi.it`. 
VPN database updates can take up to one day. Once connected to the VPN, users can log in with `<username>@10.78.18.100`; if not specified, the username is `u<person_code>` (for example, u12345678). File transfer is available via scp on the login node, e.g.:
`scp -r <username>@<source ip>:/path/to/directory/or/file <username>@<destination ip>:/destination/path` 
Users are warmly encouraged to enrol on the WeBeep course (https://webeep.polimi.it/mod/wiki/view.php?id=264943) to receive announcements about the HPC infrastructure hosted by DMAT and to gain access to the forum and additional documentation; in particular, more information on the VPN can be found in the document https://webeep.polimi.it/pluginfile.php/1183239/mod_folder/content/0/VPN_Instructions.pdf?forcedownload=1
