# File formats

Chemical JSONs are more expressive file formats. Other file formats only provide the spatial coordinates.

# Analysis features

Analyse --> Properties contains many analytical information about molecule, bonds or atoms.

# Graphics

This can be achieved with extension --> optimize geometry.
The representation can be changed with the menu on the left; a different important representation is the *Van der Waals* representation, which pictures the atoms as having the radius which they interact together with.

# Force fields

Force fields are just ways to approximate solutions of Schrodinger's equation.\
They might be well-tested for organic molecules, but not properly working in general.
